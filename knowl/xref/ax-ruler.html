Axiom 5.2.0.12. Ruler Axiom.

The distance between points has the following properties:
🔗
  1. the distance \(|AB|\) is never negative;
    🔗
    🔗
  2. \(|AB| = |BA|\text{;}\)
    🔗
    🔗
  3. if \(C\) lies on \(AB\text{,}\) between \(A\) and \(B\text{,}\) then \(|AB| = |AC| + |CB|\text{;}\)
    🔗
    🔗
  4. (marking off a distance) given any ray from \(A\text{,}\) and given any real number \(k \geq 0\text{,}\) there is a unique point \(B\) on the ray whose distance from \(A\) is \(k\text{.}\)
    🔗
    🔗
